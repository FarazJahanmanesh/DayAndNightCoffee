This source code is a simple MVC project developed over two years ago. It dates back to when I was employed as a barista at a café named "Day&Night," and during evening hours, I practiced programming by attempting to design a menu system for that café.

The project is built on C#, .NET 6, Entity Framework, and follows Clean Architecture principles.
Numerous issues may be identified in this codebase, and it can undoubtedly be refactored to a higher standard than its current state.
